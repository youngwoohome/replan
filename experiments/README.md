# Experiments

Every experiment invokes the shared `replan.serve` implementation. Model
weights, candidate traces, caches, and raw logs are supplied externally.

## Fixed-cohort experiments

Configure the common inputs:

```bash
export VLLM_ROOT=/path/to/pinned/vllm
export INPUT_ROOT=/path/to/workload-matrix
export MODEL=/path/to/model
export RESULT_ROOT=/path/to/results
export QUALITY_AMC=/path/to/amc-candidates.jsonl
export QUALITY_AIME=/path/to/aime-candidates.jsonl
export QUALITY_MATH=/path/to/math500-candidates.jsonl
```

Run one reported matrix on GPU 0:

```bash
experiments/reproduce/run_reported.sh 0 live
experiments/reproduce/run_reported.sh 0 naive
experiments/reproduce/run_reported.sh 0 midpoint
experiments/reproduce/run_reported.sh 0 order
experiments/reproduce/run_reported.sh 0 baselines
experiments/reproduce/run_reported.sh 0 allocation
experiments/reproduce/run_reported.sh 0 mixed
experiments/reproduce/run_reported.sh 0 memory
experiments/reproduce/run_reported.sh 0 branch-limit
experiments/reproduce/run_reported.sh 0 zero-slack
```

`live` generates candidates directly. The other sections replay matched
candidate answers and lengths. Use `reproduce/run_arm.sh` for one individual
condition. Each arm writes a result JSON and a same-stem vLLM runtime log.

The persistent-tail analysis selects the thesis's three frozen `N=128`,
`B=256` individual-dataset pairs per dataset from the complete result root:

```bash
python3 experiments/analysis/persistent_tail_diagnostics.py \
  --root "$RESULT_ROOT" \
  --output "$RESULT_ROOT/persistent_tail_diagnostics.json"
```

## Cross-model experiments

Generate a model-matched AIME trace and run the reported `N=64/128` matrix:

```bash
experiments/model_generalization/run_full_chain.sh \
  0 MODEL_LABEL /path/to/model false /path/to/results
```

## Open-loop experiments

See `open_loop_strict/README.md` for the Poisson and bursty arrival matrix.
Result aggregation is under `analysis/`, and the two quantitative results
figures are regenerated by `figures/plot_reported.py`.

```bash
python3 experiments/figures/plot_reported.py \
  --runtime-root "$RESULT_ROOT/baselines_mixed_n128" \
  --open-loop-root /path/to/open-loop-results \
  --output-root /path/to/figures
```
